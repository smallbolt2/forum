# 需求文档

## 1. 项目概述

### 1.1 项目背景

本项目是一个前后端分离的个人博客系统，使用Python Flask作为后端，Vue.js作为前端，MySQL作为数据库。

### 1.2 项目目标

- 搭建现代化的前后端分离开发环境
- 掌握主流开发框架的使用
- 理解RESTful API设计规范
- 学习数据库设计和操作
- 培养团队协作能力

### 1.3 技术选型

- **前端**: Vue.js 3.x + Vite + Element Plus
- **后端**: Python Flask + SQLAlchemy + MySQL
- **开发工具**: Visual Studio Code / PyCharm
- **版本控制**: Git

## 2. 功能需求

### 2.1 文章管理模块

#### 2.1.1 文章列表
- **功能描述**: 显示所有已发布的文章列表
- **输入**: 分页参数、分类筛选、标签筛选、关键词搜索
- **输出**: 文章列表（标题、摘要、作者、发布时间、浏览量、点赞数）
- **业务规则**:
  - 默认按发布时间倒序排列
  - 置顶文章优先显示
  - 支持分页显示

#### 2.1.2 文章详情
- **功能描述**: 显示文章的完整内容
- **输入**: 文章ID
- **输出**: 文章详情（标题、内容、作者、分类、标签、评论等）
- **业务规则**:
  - 每次查看增加浏览量
  - 支持点赞功能

#### 2.1.3 文章发布
- **功能描述**: 发布新文章
- **输入**: 标题、内容、分类、标签、摘要、封面等
- **输出**: 发布成功提示
- **业务规则**:
  - 标题和内容必填
  - 可以选择草稿或直接发布
  - 支持置顶功能

#### 2.1.4 文章编辑
- **功能描述**: 编辑已发布的文章
- **输入**: 文章ID和修改后的内容
- **输出**: 更新后的文章信息
- **业务规则**:
  - 只能编辑自己的文章（需要权限验证）

#### 2.1.5 文章删除
- **功能描述**: 删除文章
- **输入**: 文章ID
- **输出**: 删除成功提示
- **业务规则**:
  - 使用软删除，保留数据
  - 只能删除自己的文章（需要权限验证）

### 2.2 分类管理模块

#### 2.2.1 分类列表
- **功能描述**: 显示所有分类
- **输出**: 分类列表（名称、描述、文章数量）

#### 2.2.2 分类筛选
- **功能描述**: 根据分类筛选文章
- **输入**: 分类ID
- **输出**: 该分类下的文章列表

### 2.3 标签管理模块

#### 2.3.1 标签列表
- **功能描述**: 显示所有标签
- **输出**: 标签列表（名称、颜色、文章数量）

#### 2.3.2 标签筛选
- **功能描述**: 根据标签筛选文章
- **输入**: 标签ID
- **输出**: 该标签下的文章列表

### 2.4 评论管理模块

#### 2.4.1 评论列表
- **功能描述**: 显示文章的所有评论
- **输入**: 文章ID
- **输出**: 评论列表（内容、作者、时间、回复）

#### 2.4.2 发表评论
- **功能描述**: 对文章发表评论
- **输入**: 评论内容、文章ID
- **输出**: 评论成功提示
- **业务规则**:
  - 评论内容必填
  - 支持回复评论（嵌套评论）

## 3. 非功能需求

### 3.1 性能需求

- 页面加载时间 < 3秒
- API响应时间 < 500ms
- 支持并发用户数 > 100

### 3.2 安全性需求

- 用户密码加密存储
- API接口需要身份认证（可选）
- 防止SQL注入和XSS攻击
- 跨域请求配置

### 3.3 兼容性需求

- 支持主流浏览器（Chrome、Firefox、Safari、Edge）
- 支持响应式设计，适配移动端

### 3.4 可维护性需求

- 代码规范统一
- 完善的注释和文档
- 模块化设计
- 易于扩展

## 4. 系统约束

### 4.1 技术约束

- 前端必须使用Vue.js框架
- 后端必须使用Python Flask框架
- 数据库必须使用MySQL
- 必须实现前后端分离架构

### 4.2 环境约束

- 开发环境：Windows/Linux/macOS
- 运行环境：支持Python 3.8+和Node.js 16+
- 数据库：MySQL 8.0+

## 5. 验收标准

- 所有核心功能正常运行
- 代码通过基本测试
- 文档完整清晰
- 符合代码规范
- 前后端交互正常
